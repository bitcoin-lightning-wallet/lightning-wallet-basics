These guides explain the layer underneath the wallet: what the Lightning Network is, how a wallet relates to it, and how to tell one kind of wallet from another when the marketing all sounds the same.

If you are choosing a wallet, the comparison pages are the place to start. If you have already chosen one, the install and first-run pages cover what usually goes wrong in the first hour.

Nothing here is a ranking for its own sake. Each comparison names the custody model behind a product, because that is the property that decides what happens on the day something goes wrong, and it is the one a feature table never shows.
